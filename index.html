Web3.0 · 音乐 NFT 平台

WOM LABS Web3 音乐创作平台

Web3.0 音乐APP & PC

背景

在高度垄断的音乐市场里，新兴艺术家很难入场并盈利，多数创作者无法靠作品持续维生。项目希望打造一个开放、去中心化的音乐空间，让专业与非专业创作者都能获得更大收入，并让非区块链用户也能轻松进入。

我的角色

独立负责端到端 UI/UX 设计：从用户研究、信息架构、交互原型、视觉系统到设计规范与多端落地，全程与产品、前端协同推进。

设计过程

  • 定义核心链路：发现音乐 → 播放 → 关注 / 购买 → 收益共享。
  • 构建创作者、粉丝、收藏者三类核心用户场景。
  • 信息架构与交互：降低 Web3 门槛，简化链上购买 / 租赁 / 交易流程，突出“关注即收益”。
  • 视觉系统：暗色底 + 品牌紫渐变，统一 Web3 气质与音乐情绪，建立色彩 / 字体 / 图标 / 组件规范。
  • APP & PC 多端适配与可用性验证。

关键决策

以“收益可视化”驱动留存：粉丝关注艺术家即可获得收益，音乐原声结合 NFT 可出售 / 租赁 / 交易，收益透明地回馈创作者。

上线

完成 APP & PC 双端设计与 Design System 落地，配套 App Store 与 Whitepaper 上线物料，保证多端体验一致。

积分商城 · 国内版

WOM LABS 商城分国内与国外版本，国内版以积分兑换为核心。把积分商城兑换的周边系列化并品牌化，每一件商品都加入 WOM 自有元素，在消费与兑换中强化品牌心智。

用统一的品牌语言包装周边商品，让兑换本身就是一次品牌体验。

功能健身 · App

X-RAY 健身设备配套 App

功能健身App

背景

品牌主营可穿戴健身设备，需要一套配套的健身平台并让设备数据与 App 同步，从而提升用户粘性，让设备真正“活”起来。

我的角色

端到端 UI/UX 设计，围绕“设备 + 数据 + 社交”构建完整的训练体验。

设计过程

  • 定义设备联动场景：连接引导、数据同步、训练计划、成果分享。
  • 核心功能规划：个性化训练计划、数据追踪、找到同设备用户并分享。
  • 信息架构与交互：训练流、数据看板、社交分享三线并进。
  • 视觉系统：黑色为底、白色文字为主，以蓝色为主色调、橙色为辅助色，品牌 X 图形贯穿，围绕“LET IT OUT”打造能量化的品牌主张。
  • 可用性验证与多端适配。

关键决策

用“个性化计划 + 同好社交”形成双闭环粘性——既让用户坚持训练，也让用户因设备社区而留下。

上线

完成功能型健身 App 全案设计，支撑设备数据同步、个性化训练与健身社交分享，提升设备用户粘性。

金融科技 · 上线作品

ADDX 新加坡金融投资平台

金融科技已上线Web & APP

背景

ADDX 是新加坡受 MAS 监管的金融投资平台，面向高净值用户提供私人市场与另类投资机会。金融产品合规要求极高，需要在信息完整的前提下提供可靠、清晰、有信任感的操作体验。

我的角色

UI/UE 设计师，负责 Web 与 APP 全链路设计；主导 ADDX Design System 2.0 搭建与落地，统一多端视觉与交互规范。

设计过程

  • 合规优先的设计约束：风险披露、合格投资者、持牌提示等信息层级设计。
  • 信息架构：投资组合、钱包、交易、风险披露等核心页面的全链路梳理。
  • 针对高净值用户优化操作路径，降低决策与交易成本。
  • 搭建 Design System 2.0：统一色彩 / 字体 / 组件 / 交互规范，提升迭代效率。
  • 协助增长团队输出品牌视觉，支持海外传播。

关键决策

平衡“合规严谨”与“体验流畅”——让复杂的金融信息可读、可信、可操作。

金融科技 · 快贷网全案

快贷网 CRM 系统 & OK 合伙人

金融科技B端系统

背景

快贷网自 2012 年成立以来业务快速增长，坐席需要一套承载客户线索、进件处理与贷后跟进的系统；面对金融合规要求，界面需信息完整、层级清晰、操作高效。

我的角色

负责 CRM 系统的界面设计与迭代（V2.0 → V3.0），梳理复杂业务字段与操作流程，输出高密度但易用的 B 端界面。

设计过程

  • 梳理线索、进件、风控、贷后四条核心业务主流程。
  • 高密度表格与详情页的信息层级设计，兼顾金融字段的完整与可读。
  • 对业务状态、风险等级做视觉编码，降低坐席识别成本。
  • 多角色坐席工作台与常用操作路径优化。

关键决策

用“信息分层 + 状态可视化”降低坐席操作成本，同时满足金融合规的信息完整要求。

上线

完成 V2.0 至 V3.0 的迭代设计并支撑公司助贷业务的日常运营。

OK 合伙人 · 获客小程序

快贷网需要新的获客渠道。以“OK 合伙人”为切入点，基于微信生态用私域流量 + 圈层的数字化模式扩展获客方式，帮助业务经理线上搭建团队、实现人脉资源变现。

用清晰的收益反馈与分享链路，让“人脉变现”成为可感知、可传播的体验。
